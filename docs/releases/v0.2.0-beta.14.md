Non-Steam games, the newest XeSS XMX package, and VRR fix help.

- **Non-Steam games:** Windows games you added to Steam yourself and run through Proton now show in the Game list,
  with their own prefix when the shortcut sets `STEAM_COMPAT_DATA_PATH`, and with their icon (thanks maltyjava for
  the report and the design, tested with nine games on a Claw 8 AI+ with CachyOS!).
- **Gothic 1 Remake and other Unreal games with a launcher stub:** OptiScaler now goes next to the real game exe in
  `Binaries/Win64`, not next to the small launcher of the same name (thanks chris-hmmr!). Press **Install** again on
  the game's page to move it.
- **XeSS XMX package 20261111:** Mesa 26.3.0. On the Claw 8 EX it now runs XeSS on the XMX cores through Mesa's
  regular driver plus a small Vulkan layer, instead of a patched driver; the Claw 8 AI+ keeps the patched one.
  Setup → **Update XeSS XMX** after updating ClawDeck.
- **VRR fix:** some panels flicker or stutter at 30 Hz (below MSI's official 48 Hz floor). The Fixes page and the
  README now say so: if yours does, remove the fix and keep VRR on, it still works from 48 Hz. When the fix doesn't
  take at boot, the Fixes page now shows the kernel's own reason, and the bug report has a VRR section.
