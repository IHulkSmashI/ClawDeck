Unreal Engine games show up in the Game list again.

- **Missing games:** ClawDeck lists the games where it finds DLSS, FSR or XeSS, and it only looked 6 folders deep.
  Unreal Engine games keep those files 7 to 8 folders down (`Engine/Plugins/.../Binaries/ThirdParty/Win64`), so an
  Unreal game that isn't in ClawDeck's own game list didn't show up at all (thanks for the Mortal Shell 2 and
  The Blood of Dawnwalker report!). It now looks 9 folders deep, and every game is checked again once after the update.
- **XeSS on the XMX cores:** the same shallow search was in the launch-time check for a game's own XeSS, so an Unreal
  game's XeSS could miss the XMX cores. Fixed too.

A game that still doesn't show up has its upscaler built into the game itself, where OptiScaler can't reach it. The
full Game page lists those by name.
