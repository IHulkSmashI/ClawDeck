A safety update to beta 4's VRR fix for SteamOS and CachyOS. Please update.

- **SteamOS: the VRR fix no longer touches boot files.** SteamOS's boot setup belongs to its own A/B updates, and
  since SteamOS 3.6 an update throws away changes in `/etc` that aren't on its keep list. So on SteamOS, ClawDeck now
  hands the corrected screen description to the kernel live: nothing written to disk, no restart, applied again
  each time ClawDeck starts. If you installed the fix with beta 4, beta 5 takes its boot line out by itself; turn
  the fix on again in Fixes.
- **CachyOS: only where it's safe.** Limine is used only when your `/etc/default/limine` already sets its own kernel
  command line (otherwise Limine could write boot entries without your root partition); systemd-boot only with
  `OVERWRITE_EXISTING="yes"`; GRUB only without `grub.d` overrides. Everywhere else: the live method.
- Rebuilding the initramfs runs as its own system task, so a Steam or plugin restart can't cut it off halfway.
- Undo only ever removes ClawDeck's own line; a firmware path you set yourself is left alone.
