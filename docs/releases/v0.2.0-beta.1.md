The first ClawDeck beta: everything an Intel MSI Claw needs on Bazzite, in one Decky plugin.

**Install:** Quick Access → Decky → gear → Developer → **Install plugin from URL**, and enter
`https://github.com/IHulkSmashI/ClawDeck/releases/download/v0.2.0-beta.1/ClawDeck.zip`.
Then open ClawDeck and follow **Set up ClawDeck**. The [README](https://github.com/IHulkSmashI/ClawDeck#install) has
the full steps.

### What's in it

- **FSR 4.1.2 on the XMX cores**, downloaded for you, for DirectX 12 games with DLSS or FSR.
- **XeSS 2 on XMX** and **XeSS frame generation 2x/3x/4x**, with XeLL low latency always on.
- **One tap per game:** a pinned, tested OptiScaler with each game's fixes, REFramework for Capcom games, and an
  uninstall that puts the game back as it was. The game list tags what each game runs.
- **Power:** profiles 8–35 W, PL2, fan curves, battery charge limit, and Autotune (beta).
- **Fixes:** VRR from 30 Hz, the Claw 8 EX's MSI buttons, real watts in the performance overlay, a quieter system log.

**Tested on** the Claw 8 EX AI+ on Bazzite (CONTROL Resonant at 3x with FSR 4.1.2, Onimusha: Way of the Sword).

### Known limits

- Some flicker in Capcom RE Engine games: Intel's Linux graphics driver; see the README for a launch option that may
  help.
- Autotune with frame generation measures the capped frame rate; measure once with frame generation off.
- No gyro on the 7/8 AI+ and 8 EX.
