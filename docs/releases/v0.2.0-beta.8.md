Autotune with a target frame rate, and no more slow recovery in heavy scenes.

- **Autotune target** (Power → Autotune target): pick 30, 40, 45, 50, 60, 72, 90 or 120 fps and Autotune holds it with
  the fewest watts. It starts mid-range (or at what held the same target in this game last time), steps down in big
  steps while the game is well above the target, and settles in about a minute. When a heavy scene drops below the
  target the watts come back within seconds, and a step down that causes a drop is undone at once and not tried again
  until the game gets lighter. Set Steam's frame limit to the same number.
- **Auto FPS** (under the target): if the full TDP can't reach your target for a minute, Autotune holds the closest
  frame rate it can instead of running flat out, and climbs back toward your target when the game gets lighter.
- **Faster recovery without a target too.** Autotune used to lower the TDP in a calm scene and then take minutes to
  give the watts back when the game got heavy (thanks for the Resident Evil 4 report). Now a heavy scene gets them back
  at once, and Autotune stops lowering below that point for the session.
- **Frame generation:** Autotune always counts the frames the game renders (base fps), with XeSS frame generation and
  with ClawDeck's other frame generation too.

The target mode follows the governor of [DeckyTDPTuner](https://github.com/sidharthify/DeckyTDPTuner) (thanks!),
re-done for Intel's power limits.
