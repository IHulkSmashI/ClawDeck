A small fix to beta 5's VRR fix on SteamOS.

- **SteamOS: no more "VRR fix not changed".** Beta 5 tried to hand the corrected screen description to the kernel
  live. Thanks to a tester on SteamOS 3.9.5 we now know Intel's graphics drivers (i915 and xe) read the built-in
  screen's description once at boot and keep it, so the live method can't reach it. ClawDeck put everything back
  when it didn't take, so nothing changed on anyone's Claw.
- So ClawDeck no longer offers the live method on Intel's built-in screen. Where no method can apply (SteamOS today),
  Fixes says why instead of showing a button that fails. SteamOS support through a boot setting that survives SteamOS
  updates is in the works. Bazzite and CachyOS keep the fix as before.
