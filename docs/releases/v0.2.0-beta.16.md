Non-Steam games with their own Proton prefix.

- **Non-Steam games with a custom prefix:** when a shortcut's launch options send Proton to its own prefix
  (`STEAM_COMPAT_DATA_PATH=...`), ClawDeck now always uses that one. Steam creates an empty `compatdata` folder for the
  shortcut at its first launch, and ClawDeck looked there instead, so the Game page said the XMX cores were never used
  and the health check looked in the wrong place. XeSS on XMX itself kept working. A path starting with `~` or `$HOME`
  works too (thanks maltyjava for tracking it down!).
