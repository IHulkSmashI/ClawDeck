The newest XeSS XMX package and REFramework build.

- **XeSS XMX package 20261107** (from 20261104): sturdier driver, XMX helper and Proton hook; missing XMX programs
  now compile in the background instead of waiting on the first frame; a Cyberpunk 2077 crash fixed on Mesa 26.3;
  the driver check at log-in falls back to the stock driver safely if the package folder is ever moved.
  Setup → **Update XeSS XMX** after updating ClawDeck.
- **REFramework (Capcom games) release 18** of onehoon's fork, the build OptiClick's Capcom setup uses (from release
  15): bug fixes from REFramework itself for script loading and hook handling. On a game you already set up, press
  **Install** again on its Game page to get the new build.
