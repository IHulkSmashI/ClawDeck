SteamOS and CachyOS, two more handhelds, and the VRR fix outside Bazzite.

- **Works on Bazzite, SteamOS and CachyOS.** ClawDeck no longer talks as if every system were Bazzite.
- **VRR fix 30–120 Hz on SteamOS and CachyOS (new, please test).** Those systems have no `rpm-ostree`, so the fix
  couldn't install there. Now it hands the corrected screen description to the kernel live: no restart, nothing
  written to disk, applied again each time ClawDeck starts, off at once when you turn it off. If the system restarts
  within a minute of applying it, ClawDeck leaves it off next time, so a problem can't repeat at every boot. Bazzite
  keeps the method it had.
- **New beta devices:** Acer Predator Atlas 8 (XeSS, FSR 4.1.2 and frame gen on XMX, power; Linux has no fan or
  charge-limit driver for it yet) and OneXPlayer X1 Air (XMX, power, fan, charge limit).

**Install or update:** coming from beta 3, Setup → **Update to 0.2.0 beta 4**. Otherwise Quick Access → Decky → gear →
Developer → **Install plugin from URL**, and enter
`https://github.com/IHulkSmashI/ClawDeck/releases/download/v0.2.0-beta.4/ClawDeck.zip` (from beta 1 or 2, run Set up
ClawDeck again afterwards).

**On SteamOS?** Try Fixes → Install VRR fix and tell us how it goes, with Setup → Export log attached:
[bug report](https://github.com/IHulkSmashI/ClawDeck/issues/new?template=bug_report.md).
