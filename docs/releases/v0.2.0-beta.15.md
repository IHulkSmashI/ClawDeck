The VRR fix works on CachyOS with Limine.

- **VRR fix on CachyOS + Limine:** Limine reads its boot settings line by line, so the label ClawDeck put after its
  setting ended up on the kernel command line and the fix never took ("started with the fix, but the driver still
  reports 48-120"). The label now goes on its own line. If you already installed the fix, ClawDeck repairs the line by
  itself when it starts: one restart and you're on 30–120 Hz (thanks maltyjava for finding it, and Rafalskyy for the
  report!).
