The VRR fix comes to SteamOS.

- **VRR 30–120 Hz on SteamOS.** Turn it on in Fixes, restart once. ClawDeck does it the way SteamOS itself is set up:
  one marked line in `/etc/default/grub`, then SteamOS's own `update-grub`. Nothing in SteamOS's read-only system is
  touched, and the initramfs stays Valve's.
- **Survives SteamOS updates.** ClawDeck puts only its own screen file on SteamOS's keep list
  (`/etc/atomic-update.conf.d/clawdeck-vrr.conf`). Valve's grub file is deliberately not kept, so their changes to it
  always come through. After an update ClawDeck adds its one line again by itself; one restart brings 30–120 Hz back.
- **Remove** in Fixes takes out the line, the keep-list entry and the screen file, and puts Valve's file back exactly.
- Beta 4's leftover SteamOS boot line is now really cleaned up (beta 5 and 6 looked for SteamOS's boot menu in the
  wrong place).
