XeSS through OptiScaler reaches the XMX cores again, and a one-tap debug log for when it doesn't.

- **XeSS 2 on the XMX cores:** OptiScaler loads XeSS when the game starts, and Proton 11.0 then reported the Claw's
  GPU to XeSS as an AMD one, so XeSS took its slower DP4a path instead of the XMX cores. Every game with XeSS 2
  through OptiScaler now shows XeSS the Intel GPU, with or without frame generation. Existing games pick it up by
  themselves (thanks quarter24am for the logs from Tainted Grail on the Claw 8 AI+!).
- **Debug logs for the next launch:** Per-game → *Something not working?* turns on Proton's log, the XMX driver's
  messages and OptiScaler's log for one launch. Play a minute, quit, then Setup → Save a bug report: the report
  shows where things stopped. The next launch is normal again.
- **The Witcher 3 and DLSS:** since its 5.0 update the game turns DLSS off when it runs under Proton, before
  OptiScaler sees it. The Game page now says so: pick XeSS in the game's menu, or run it with GE-Proton 11-9 or newer.
