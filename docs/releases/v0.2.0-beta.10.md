Two fixes.

- **The Witcher 3: DLSS shows up again.** The game has a DirectX 11 and a DirectX 12 copy of `witcher3.exe`, and
  ClawDeck could put OptiScaler next to the DX11 one, where the game has no DLSS, FSR or XeSS. ClawDeck now always picks
  the DX12 folder, and moves an earlier install over. After updating, press Install again for the game, and run it in
  DirectX 12 (pick it in the game's launcher, or add `--launcher-skip -dx12` after `%command%`). Thanks for the report!
- **Gyro (Claw 8 EX):** confirmed working by Kisenir on his EX. If you set the gyro up by hand before from his guide,
  ClawDeck's install now turns those hand-made services off instead of running two copies that fight each other.
