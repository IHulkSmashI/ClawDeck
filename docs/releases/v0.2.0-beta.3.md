XMX on every Proton, an update button, and logs that say what happened.

- **XMX works whatever Proton a game uses.** GE-Proton, Proton Experimental and proton-cachyos put Intel's stock XeSS
  file into the game at every launch, so XeSS and FSR 4.1.2 lost the XMX cores there, and FSR 4.1.2 went black.
  ClawDeck now fixes the game's Proton right before it starts (tested: CONTROL with FSR 4.1.2 and frame generation
  on GE-Proton 11-12).
- **Update button** in Setup: shows your version and the newest one, and updates through Decky with one tap. Your
  settings, the XMX driver and your game setups stay.
- **FSR 4.1.2 is held back** in a game whose last launch didn't use the XMX cores, so you don't get a black screen;
  one launch with XeSS 2 brings it back.
- **Better bug reports:** every launch is logged, and Export log now shows each game's settings, its last launch and
  whether the XMX cores ran.
- FSR 4.1.2 for games set up by Decky Framegen now gets the XMX file it needs.

**Install or update:** Quick Access → Decky → gear → Developer → **Install plugin from URL**, and enter
`https://github.com/IHulkSmashI/ClawDeck/releases/download/v0.2.0-beta.3/ClawDeck.zip`.

**Coming from beta 1 or 2:** Decky removes the old version before it installs the new one, and the old version cleans
up after itself, so open ClawDeck afterwards and run **Set up ClawDeck** again, then re-apply your games in Per-game.
This is the last time: from beta 3 on, the Update button keeps everything. (The Konsole line in the README's
install steps updates without that reset, if you'd rather.)
