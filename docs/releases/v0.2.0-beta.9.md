Gyro on the MSI Claw 8 EX (beta).

- **Gyro (beta)** in Fixes, Claw 8 EX on Bazzite. The EX's gyro sits behind Intel's sensor hub, which needs MSI's
  firmware. One button: ClawDeck downloads MSI's sensor-hub kit, checks the exact firmware file before it writes
  anything, installs it with a small program that lets Linux read the gyro, and tells InputPlumber to pass it to
  Steam as a Steam Deck gyro. Then **shut the Claw down fully and turn it on again** (a cold boot), and recalibrate
  gyro once in Steam's controller settings.
- **Accelerometer too** (under Gyro), off by default: Steam mixes it with the gyro and gyro aiming gets worse. Turn it
  on for tilt games.
- **Remove gyro** takes every piece out again.

**Autotune, if you're coming from beta 7 or earlier** (new in beta 8):

- **Autotune target** (Power → Autotune target): pick 30, 40, 45, 50, 60, 72, 90 or 120 fps and Autotune holds it with
  the fewest watts. It settles in about a minute, gets the watts back within seconds when a heavy scene drops below the
  target, and doesn't try a lower wattage again until the game gets lighter. Set Steam's frame limit to the same
  number.
- **Auto FPS:** if the full TDP can't reach your target, Autotune holds the closest frame rate it can instead of
  running flat out, and climbs back when the game gets lighter.
- No target set: a heavy scene gets the watts back at once instead of minutes later.
- With frame generation, Autotune counts the frames the game renders (60 with 2x frame generation shows about 120).

The method is **Kisenir**'s (r/MSIClaw): he found how the EX's gyro hides behind the sensor hub, which MSI firmware
file brings it up, and wrote the program and helpers ClawDeck installs. Thank you!
